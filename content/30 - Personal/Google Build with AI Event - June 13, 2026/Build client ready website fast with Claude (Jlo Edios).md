# ⚡ Build Client-Ready Websites Fast with Claude

## 🎯 Keynote: Jlo Edios

## ⚠️ Cheat Skills & Efficiency
- Everyone can build websites, but are they doing it correctly?
- We need to learn how to **maximize credits** and avoid AI slop.
- Key Tools:
  - **Claude Co-Work:**
    - Can create, edit, and organize files in the cloud.
    - Uses lightweight **handoff `.md` files** for context preservation.
    - Core focus on **Context Engineering**.
  - **Claude Design:** High-fidelity visual implementation.
  - **Claude Code:** Terminal-based coding agent.

## 💡 `CLAUDE.md` is Your Context Router
- Define project rules, custom instructions, and style guides (e.g., removing em-dashes and AI clichés).

## ✅ SOP to Rules to Skills
- **SOP $\rightarrow$ Rules $\rightarrow$ Skill**
- Turn repeatable workflows into portable skills that anyone on the team can invoke.

## 🔥 Build Fast with ASTRO
- **Astro** ships zero unnecessary JS by default, generating fast, lightweight static pages.

## ⚙️ Recommended Stack: GitHub + Vercel + Neon
- Fast git-driven deployments paired with serverless PostgreSQL.

## ❓ How to Replicate and Build Fast
1. Download / save reference HTML.
2. Take a **screenshot** of the target layout and pass it directly to Claude.
3. Iterate with granular prompt handoffs.
